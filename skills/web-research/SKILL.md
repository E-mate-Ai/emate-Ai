# Web research

Use this skill only when a trusted web-search tool is enabled for the request. Never claim to have browsed or fabricate sources. Prefer primary sources, compare publication and event dates, cite each material claim, and label inference. If search is unavailable, say so and answer only from stable knowledge or user-provided sources.
